# VocaTech Project Manager

Веб-сервис управления проектами VocaTech.

Стек:
- React + Vite
- Supabase Auth
- Supabase PostgreSQL
- Supabase Storage
- Supabase Realtime

Роли:
- creator — создатель системы
- admin — администратор
- user — пользователь

Основные модули:
- проекты
- канбан-задачи
- план-график пилотов
- роли и права доступа
- результаты задач и вложения
